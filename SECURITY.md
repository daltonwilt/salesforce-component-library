# Security Policy

## Supported Versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, report them privately through GitHub's private vulnerability reporting:

1. Go to the [Security Advisories](https://github.com/daltonwilt/salesforce-component-library/security/advisories/new) page.
2. Fill in the form with as much detail as you can.

Please include:

- The type of issue (for example, SOQL injection, cross-site scripting, sharing or CRUD/FLS bypass)
- The affected component, class, or file path
- Steps to reproduce, or a proof of concept
- The potential impact

## What to Expect

- An acknowledgement of your report within 7 days
- An assessment and, where confirmed, a plan for a fix
- Credit in the advisory once the issue is resolved, unless you prefer to remain anonymous

Please give reasonable time for a fix to be released before disclosing the issue publicly.
